# rusty_nexus — archived

This repository is archived. It was a one-session (2026-07-25/26) spike that
re-derived the Nexus design on the `rusty_*` platform crates. It does not
build standalone and has no successor code.

All development continues in **[baileyrd/nexus](https://github.com/baileyrd/nexus)**.
The assessment that led to this decision is
[RFC 0009 — four-repo consolidation](https://github.com/baileyrd/nexus/blob/main/docs/0.1.2/rfcs/0009-four-repo-consolidation.md).
